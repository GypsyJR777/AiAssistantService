# ИИ-агент
## Стек
- kotlin 2.1
- langchain4j 1.5
- Quarkus 3.24.3

## AS-IS
Два модуля:
- ai - модуль-библиотека для взаимодействия с LLM, сейчас реализовано подключение к Ollama, OpenAI и OpenAI Compatible
- server-rest - модуль на данный момент только с ботом для Telegram 

## TO-BE
В планах сделать больше модулей, больше описаний ИИ-агентов/ассистентов.
Модульность:
- ai - модуль-библиотека для взаимодействия с LLM, сейчас реализовано подключение к Ollama, OpenAI и OpenAI Compatible
- security - модуль для настройки безопасности взаимодействия
- server-rest - модуль с REST API, который будет взимодействовать с возможными другими агентами или сразу с LLM
- server-bot - модуль с ботом для Telegram, возможно добавить еще бота для VK
- home-module - модуль для взаимодействия с системой умный дом

Также в дальнейшем возможно разделение на несколько разных репозиториев с разным стеком

## Логика при старте
- Запуск сервера
- Чтение конфигурационных файлов
- Создание инструментов для ИИ
- Создание соединения с LLM
- Создание соединения с TG
- Включение бота TG 

## Логика при сообщении от пользователя бота Telegram 
- Обработка сообщения
- Команда /chat
  - Отправка ответного первичного сообщения
  - Отправка запроса в ИИ
  - Ожидание ответа
  - Изменение ответного сообщения - добавление модуля think 
  - Отправка итогового ответа 

## Проблемы на данный момент (те что нашел)
- Если ответ от ИИ очень долгий - сообщение не отправляется, просто теряется
- Не до конца верно обрабатывается think, логика у Ollama и OpenAI разная
- Команды не видны в TG
- Нужна отдельная команда /help
- Удалить бы команды на /chat - сделать так чтоб все сообщения без команд - взаимодействие с ии
